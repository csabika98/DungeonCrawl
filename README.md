# 🏰 DungeonCrawl

---

## 📖 Introduction

**DungeonCrawl** is an RPG game (roguelike game) that immerses you in a dungeon-crawling adventure.

---

## 🔑 Key Features

- **Load & Save System**: Save your current progress with a simple `Ctrl + S` command, utilizing PostgreSQL for data storage.
- **Item System**: Pick up various items like swords, apples, and more to enhance your gameplay.
- **Shield System**: Collect shields to become stronger; your character also gets a new skin when equipped with a shield.

*Developed using Java and JavaFX.*
